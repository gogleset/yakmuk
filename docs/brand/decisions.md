## 파생 규칙

- **1차 beat:** F1 · F2 · **F6** (F3 없음)
- **`happy.png`:** 에셋은 두되 1차 UI 미연결 (F6=`done`). 나중에 강화용
- **Streak 계산:** 오늘 포함 과거로, 스케줄 있는 날만 all-done이면 연속 +1. 스케줄 0개인 날은 연속 끊지 않음(스킵). 미완/부분 = 끊김
